# 行业与企业发展潜力评估交付模板

## 一、交付载体

实际建模默认交付 **Markdown 主报告＋同内容 HTML 阅读版＋可编辑、可复算 Excel**。Markdown 是内容基准，解释行业、子赛道或企业的比较结果、成因与实际含义；HTML 提供适合屏幕和打印阅读的完整报告；Excel 呈现并比较维度、权重、得分和依据。用户只要求方法或模板时，交付模型设计与参数表；只需对话答复时在对话中交付。

## 二、Markdown 主报告

按下列顺序平铺章节，围绕实际发现展开：

1. **核心摘要**：目标处于什么水平，与理想模型和历史参照差在哪里；哪些赛道或企业值得关注，关键理由是什么。
2. **研究范围**：对象、主要评价用途（当前实力或未来潜力）、地域、观察时点与判断期限、参照对象及所用建模模式。
3. **理想模型与参照选择**：理想发展需要什么条件，为什么；历史高峰为何适合类比，当时具备哪些条件、仍有什么短板；当前参照提供什么比较价值。
4. **评价维度、指标和权重**：用概览展示一级维度、指标层级和权重，简述选择理由及评分含义；详细分档、公式和逐项权重理由放入附录或 Excel。
5. **分维度差距与成因**：每个一级维度单独解读，先给本维度的比较结论，再结合关键事实说明目标与历史、当前参照及理想条件的差距体现在哪里、为什么形成、怎样影响发展位置、竞争力或投资吸引力。围绕关键指标串起因果，解释优势如何保持、短板能否补齐及需要什么条件。得分和分差用于概括比较；正文主要篇幅用于分析这些差异的实际含义。
6. **综合判断与机会**：给出综合位置、子赛道优先级或企业竞争机会，解释可补齐的条件和主要制约。按加权分差定位主要短板，再结合可控性、投入、时间和前置条件确定改善优先级；关键路径列出触发条件、指标变化与总分变化，区分当前结果和改善情景。组合模式同时解释子赛道与母赛道的关系。
7. **参数变化与结论稳定性**：哪些权重、评分或假设变化会改变排序，变化多大；存在准入、安全等硬约束时说明其影响。
8. **研究说明与附录**：简述搜索与研读范围、目标及参照的材料覆盖；收纳评分标准、逐对象逐指标的事实与赋分理由、估算口径、来源索引及影响判断的待补资料。Excel 已完整承载的明细可链接到具体表名与位置。

正文保留支撑论证的关键事实和来源标注，详细材料与赋分说明放在后面。读者先看清差距、成因和含义，再按需追查依据；表格辅助比较，分析段落解释表格没有直接表达的机制与判断。

## 三、HTML 阅读版

Markdown 主报告定稿后，按[HTML报告交付规范](HTML报告交付规范.md)生成同内容 HTML。HTML 保留全部实质章节、结论、评分与分差、表格、图表、来源和附件入口，不把完整报告缩成摘要页，也不替代可调 Excel。

HTML 使用随包固定模板和生成器。核心摘要优先展示结论；主体仍按 Markdown 的章节顺序呈现理想模型、参照选择、评价体系、逐维度差距、综合判断和敏感性分析；文末提供来源及 Excel 工作簿入口。

## 四、Excel 工作簿

全工作簿的指标分、维度分、综合分统一为 **0—100分**，分差单位为分、可正可负，权重显示为百分比。首页能直接看出“维度—目标—参照—差距”，并提供各表用途及调参位置。

### 五张基本表

| 表名 | 读者在这里看什么、做什么 |
|---|---|
| **模型总览** | 先看各维度权重、目标与参照的维度分、综合位置、主要差距和研究结论；从这里进入其他表 |
| **锚点参照与赋分意义** | 将理想模型、历史高峰、当前参照与目标逐指标并排；显示维度归属、权重、得分和分差，以及参照选择理由；可调整参照评分 |
| **指标详表** | 查看评分标准，调整全局指标权重和目标评分；公式自动更新维度权重、维度分、总分与分差 |
| **模型假设** | 查看为何选择这些维度、权重和评分标准；逐对象列出事实依据、评分理由及理想条件；保存估算、参数与口径说明 |
| **数据溯源** | 查评分所用的原始材料、时间和来源链接；区分原始事实、估算与分析师判断 |

调整入口采用蓝色字和浅蓝底，公式格采用黑字。权重只有一处输入，其他表引用它；评分也从各自输入位置引用。首页说明改动后需要复核哪些文字结论。

### 指标、权重与评分依据

`指标详表`第3行为全局权重，第4行为评分标准，第5行起为对象。综合分使用单元格引用，例如：
`=IF(COUNT(B5:C5)=2,SUMPRODUCT(B5:C5,$B$3:$C$3)/SUM($B$3:$C$3),"")`。

维度权重为所属指标全局权重之和，维度内权重为指标全局权重除以维度权重。总分是全局加权平均；所有比较对象使用同一套当前权重。显示权重合计，调参后以合计100%保存基准版本。

`模型假设`中每个对象×指标一行：
`对象｜维度｜指标｜当前得分｜评分理由｜事实与来源编号`。
理想构型同样逐指标说明满分条件及理由。评分是分析结果，原始材料记录实际值与事实，不要求来源本身提供“多少分”。

### 按需增加的表

- **组合加权**：评价母赛道时使用。列子赛道、规模或其他组合权重、权重来源、各指标和整体得分；权重可调并联动汇总。注明评价用途、权重口径与时期；调参后除以权重合计归一化，基准版本合计100%。权重缺失、负值或合计为零，以及所需评分缺失时，对应汇总留空，修正输入后恢复计算。
- **计算审计**：指标包含多步计算时使用。列原始值、来源、转换公式、子指标权重与得分、最终指标分，便于复算。
- **敏感性**：比较多个权重或评分方案时使用。列基准、调整值、总分和排序变化、翻转条件及解释；简单变动可在主报告说明。

### 随包脚本

`examples/model-input.example.json`演示输入结构，标注为教学假设。
- `model.score_scale`设为100；指标、对象及参照评分均为0—100。
- `dimensions`写名称、回答的问题和研究依据；`indicators`写归属、全局权重、选择理由和评分标准。
- 对象和参照用`scores`记录分值或公式，`score_reasons`记录逐项理由；`sources`记录实际证据并关联对象和指标。参照另写选择理由与时期。
- 确实无法评价的项用`null`，附缺失原因；已有指标和维度结果继续显示。
- `rating_rules`按需要填写；组合模式填写`combination`（`weight_basis`可说明权重口径，省略时沿用市场规模占比），复杂计算填写`calculation_audit`。

安装`requirements.txt`中的依赖后运行：
```powershell
python scripts/build_scoring_workbook.py --input [输入.json] --output [工作簿.xlsx]
python scripts/validate_scoring_workbook.py --workbook [工作簿.xlsx] --contract [输入.json]
```

旧十分制输入需将评分、评分公式和分档统一换算，再生成新版；原始统计数据的单位保持原样。

## 五、保存与命名

沿用用户指定目录；未指定时保存在当前项目工作目录。Markdown 与 HTML 使用相同文件名主体，默认名称为`YYYYMMDD_主题_发展潜力评估报告.md`、`YYYYMMDD_主题_发展潜力评估报告.html`和`YYYYMMDD_主题_发展潜力评分模型.xlsx`，版本及制作方后缀遵循项目约定。

## 六、信息缺口

发现缺口先补查、尝试事实分档、合理代理或区间；指标难以操作时修订定义。仍无法判断的项，列出影响和补充方式。工作簿保留空值及已完成的维度比较，总分在所需评分具备时计算。

## 七、交付前检查

1. 搜索与研读覆盖目标、参照及主要发展条件；维度选择有材料与机制依据，名称直白，比较采用共同标准。
2. 理想条件、参照选择、权重和逐项评分均有理由；事实与分析判断能对应。
3. 首页能看懂强弱与差距；逐维度正文能解释差距的事实表现、成因和实际影响，读者无需先读赋分明细即可理解发展判断、关注方向或竞争机会。
4. 全部评分采用百分制，权重和评分可调；实际改动一个权重、一个分数，检查维度、总分和分差联动。
5. 核对来源、公式、组合汇总、参数变化及必要硬约束，Markdown、HTML 与工作簿数值一致。
6. HTML 保留 Markdown 全部实质内容及 Excel 入口；桌面端、390px 窄屏和打印版式通过检查，或在交付清单中明确标注尚未完成的渲染检查。

逐段检查：只为避免质疑、风险、责任或自我辩解，却没有增加事实、推理、执行方法或有用判断的文字，删除；重复提醒、预先反驳假想质疑和反复声明自己没犯错，也按此处理。会改变结论、适用范围或行动的条件，在最相关位置解释一次。
