# 发展潜力评估 HTML 报告交付规范

本规范用于行业、子赛道和企业的发展潜力评估。HTML 是定稿 Markdown 主报告的完整阅读版，与可调 Excel 一并交付。

## 一、输入与内容边界

- 输入是已经完成内容、数据和模型一致性检查的 Markdown 主报告，以及对应 Excel、图表和附件。
- Markdown 是内容基准。HTML 可以调整版式，但须保留全部实质章节、核心结论、分数、分差、表格、图表、来源和附件入口，不改写结论强度或评分口径。
- HTML 不替代 Excel。权重、评分和参数仍在 Excel 中调节；HTML 应提供工作簿入口，并说明调参后哪些报告结论需要复核。
- 页面不展示 Skill 调用过程、内部审核记录和只服务于生产过程的说明。

## 二、固定版式

使用随包[研究报告 HTML 模板](../assets/研究报告HTML模板.html)：桌面端为深蓝固定目录栏、浅灰蓝画布和白色正文页；章节标题使用红色竖线；核心摘要使用结论卡片。常规交付只填充内容，不另写页面或追加一套样式。

- 桌面正文页最大宽度约 1060px，固定目录展示二级章节。
- 宽度小于 1080px 时改用正文顶部折叠目录；小于 720px 时卡片单列，表格横向滚动。
- 全文只有一个 `h1`。Markdown 原有章节编号保持不变，不再添加红色序号或另一套编号。
- CSS 和必要脚本内嵌，不依赖 CDN、在线字体或远程脚本。图片使用 data URI 或随报告交付的稳定相对路径。
- 打印样式隐藏目录和按钮，按 A4 排版，避免标题、卡片和图表在分页处截断。

## 三、页面内容

HTML 按 Markdown 原顺序呈现：

1. **封面**：报告标题、结论型副标题、研究范围、数据截止日和版本。
2. **核心摘要**：并列结论排成卡片，引言和收尾保留通栏；摘要先回答目标所处位置、关键优势、主要差距和关注方向。
3. **模型与参照**：保留理想模型、历史高峰、现实参照、维度体系、权重和评分口径。
4. **分维度分析**：逐维度保留对象得分、关键分差、成因、发展或经营含义，以及需要补齐的条件。
5. **综合判断与稳定性**：保留综合位置、机会、限制、敏感性、排序翻转条件和必要硬约束。
6. **来源与附件**：保留来源索引、口径说明和可编辑 Excel 工作簿入口。Excel 使用相对链接并与 HTML 一同交付。

## 四、生成步骤

1. 确认 Markdown 首个正文章节为“核心摘要”，报告、Excel 和附件已定稿。
2. 安装 `requirements.txt` 中的依赖，使用随包 `scripts/build-html-report.py` 填充固定模板：

   ```bash
   python scripts/build-html-report.py 主报告.md 主报告.html --report-type "行业与企业发展潜力评估报告" --scope "目标与参照范围" --data-cutoff "YYYY-MM-DD" --version "V1.0"
   ```

3. 脚本默认不覆盖已有 HTML；确需覆盖时显式增加 `--overwrite`。脚本检查唯一一级标题、摘要顺序、正文文字一致性、重复锚点、失效内部链接和远程图片。
4. Markdown 与 HTML 使用相同文件名主体。Excel 链接采用同目录相对路径；交付前确认链接指向实际文件。
5. 逐节核对 Markdown 与 HTML 的章节、结论、数字、评分表、图表、来源和附件入口。

## 五、交付检查

- [ ] 标题、范围、截止日、版本和评分口径与 Markdown 一致。
- [ ] 全部实质章节、逐维度结论、数字、表格、图表和来源均已保留。
- [ ] Excel 入口可用，工作簿与报告的对象、权重、评分、分差和综合结果一致。
- [ ] 目录锚点可达，没有额外或重复章节编号；摘要卡、正文和表格使用固定模板样式。
- [ ] 1440px 桌面端无内容遮挡；390px 窄屏正文不横向溢出，宽表可滚动；打印预览不显示侧栏和按钮。
- [ ] 关闭网络后仍可打开和阅读；若未完成实际渲染检查，交付清单明确标注“渲染未验证”。
