# 行业建模的信息搜索与研究加工

本流程服务于维度设计和赋分：广泛搜集目标及参照的公开材料，读出发展机制和差异，再形成可比较的指标。完整建模默认执行多轮搜索；用户提供的已有研究及其原文可以承接对应工作，新搜索补足对象、时期和问题覆盖。用户限定只用现有材料时沿用该范围。

## 一、把研究问题转成搜索任务

列出目标行业或企业、子赛道、历史高峰候选及当前可比对象，分别明确地域、时期和待查问题。先按下表展开，随着材料出现新对象、新机制或新矛盾继续扩充。

| 搜索方向 | 要读懂什么 | 重点材料 |
|---|---|---|
| 需求与市场 | 谁需要、为何购买或放弃，空间与增长来自哪里 | 统计、行业研究、采购、消费调查、客户与用户反馈 |
| 发展条件与障碍 | 政策、经济社会、技术、成本、法律怎样促进或限制发展 | 政策及执行材料、社会经济数据、论文、标准、产品测评 |
| 产业与经营 | 供应链、渠道、竞争、盈利、资金需求，成功与失败的原因 | 企业披露、产业研究、客户案例、公开访谈、退出与经营困难案例 |
| 目标与参照 | 历史高峰怎样形成、仍有什么短板，各对象今天差在哪里 | 历年统计、同期披露、产品与市场记录、历史复盘、当前原始材料 |
| 企业特有条件 | 团队、产品、客户验证、商业化、资金和组织怎样支持竞争 | 创始团队经历、产品文档、客户采购、公开融资与经营材料 |

关键词由`对象词＋问题/材料词＋时期或地域`组合。补充中文名、英文名、简称、旧称、上下位品类、代表企业和替代产品；同时搜索采用、增长、成功，以及退货、退出、失败、替代和未被满足的需求。使用公开材料常见词，再从原文发现新的查询词。

搜索计划只需写清`待查问题｜对象与时期｜关键词组合｜目标材料与渠道｜需带回的事实`。已有统一搜索计划时直接追加。`sou-cha-ling` 可协助设计，有无该 Skill 都可按本页执行。

## 二、逐轮搜索与研读

完整研究覆盖以下三类搜索，发现重要新问题时继续迭代：

1. **广搜全貌**：覆盖目标、细分及参照候选，查定义、发展历程、产业结构、市场、政策、技术和主要企业。获取综述后追到引用的统计、论文、披露及原始案例，形成行业问题清单。
2. **深查机制**：围绕增长来源、关键成功条件、痛点和发展瓶颈，查不同角色与正反案例。研究历史高峰的同期条件，与目标逐项比较，从中归纳一级维度和指标候选。
3. **补齐评分依据**：按候选维度逐对象查实际表现、可观察差异、标尺依据及关键冲突。试评后调整指标或补搜，完成“事实—判断—分数”的对应。

每轮记录新增发现及它怎样改变问题、参照、维度或评分。充分扩展有用材料的来源、类型、对象与时间覆盖，材料持续带来新的有效解释时继续扩展；相关主题已有较充分覆盖、新增材料主要重复时，将精力转向尚有分歧和缺口的维度。同一新闻的转载合并为一个事实来源。

## 三、按材料类型使用搜索能力

| 能力 | 用法 |
|---|---|
| 通用网页搜索与浏览 | 多组查询发现来源，再打开原文，沿引文和相关对象继续查 |
| 原始网站与专业数据库 | 查政府统计、政策执行、监管与交易所披露、公司资料、招投标、行业数据 |
| 论文、专利、标准与技术文档 | 技术或AI是重要发展条件时，查论文/预印本、独立测试及落地情况；关键论文读方法、结果和适用范围 |
| 客户、用户与专业社区 | 查采用、使用效果、痛点、替代与不采用原因，保留主体和场景，结合调查或经营数据判断影响 |
| 当前可用的采集 Skill、MCP/API、正文及文件提取 | 扩大平台覆盖、批量取回正文、解析PDF/表格；一个入口受限时换原站、其他检索或提取路径 |

涉及国际对象或海外历史参照时补英文及相关本地语言来源。已知网址或文件直接读取；不同能力分工获取材料。搜索摘要用于定位线索，进入维度选择或赋分的关键事实需读取原文或可核对的正文摘录。渠道失败仅记为该渠道未取得，并继续尝试其他可用入口。

## 四、共用材料索引并加工为研究依据

沿用项目材料库；独立项目在输出目录下设`材料/`。原文、关键摘录和材料索引保存在这里，已有资料使用原位置。索引至少记录：`编号｜标题/机构｜发布与取得时间｜对象与时期｜原文链接/文件及页码｜正文状态｜关键发现｜审核状态`。

关键材料读正文、表格与方法说明，提炼事实和因果解释。有 `baojie` 时调用它审核；不可用时自行核对主体、时期、地域、定义、单位、重复与冲突。评分影响大的争议事实优先寻找独立来源交叉核对；历史参照以所选时期的状态为准，后来的复盘用于解释。

在索引旁维护一张研究表即可：

`发展条件/问题｜目标及参照的事实与材料编号｜机制与差异解释｜候选维度/指标｜标尺或赋分依据｜下一步补搜`

按主题归并多份材料，解释该因素怎样促进或制约发展、为何重要，再抽取维度；理想条件由这些机制及成功、失败案例推导。进入评分时，把事实映射到共同标尺并说明给分理由。研究表可并入已有底稿，最终引用同一材料编号写入报告与工作簿，无需重复建清单。

## 五、从研究推进到模型

主要发展条件已被材料和案例解释、目标及参照能按共同含义比较时，形成维度方案；各项事实能够支持档位或数值判断时完成赋分。发现某对象、维度或时期的材料明显偏薄，按具体问题补搜并继续加工。

精确统计值不足时，可用已核对的事实分档、合理代理或有依据的区间完成评价；已有重要矛盾要查明口径或比较不同解释。补搜后仍无法判断的项，按主文缺口处理。研究资源优先投入这些环节，再完成表格制作与结果呈现。
